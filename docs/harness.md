# Жгуты Double Row 18 Tubes — throttle и reverse

Каталог JRAHK не печатает цвета проводов. Ниже — **типовая** распиновка e-bike/EV BLDC-контроллеров этого класса. Перед пайкой **обязательно** сверить мультиметром на вашем экземпляре (цвета у китайских жгутов плавают).

## Throttle (скорость 0–5 В)

Обычно 3-pin разъём (иногда в составе 5–6 pin с доп. функциями).

| Типичный цвет | Функция | Что делать с Raspberry / DAC |
|---|---|---|
| Red | `+5V` от контроллера (~5 В относительно GND) | **Не подключать** к выходу DAC и к GPIO Pi |
| Black | `GND` | Общий GND с платой управления (Pi + MCP4728) |
| Green / Yellow / White / Blue | `SIG` (вход скорости) | Выход MCP4728 `OUTx` (0–5 В) |

### Проверка мультиметром (контроллер под батареей, мотор можно не крутить)

1. Между Red и Black: **~4.8–5.2 В** постоянно.
2. Между SIG и Black без ручки газа / с разомкнутым SIG: обычно ~0–1 В (зависит от модели).
3. Подать с лабораторного БП / DAC на SIG относительно Black:
   - ~**0.0–1.0 В** — стоп / deadzone
   - ~**1.0–1.2 В** — часто порог трогания
   - ~**4.0–4.2 В** — типичный полный газ (не обязательно 5.0 В)
4. Записать для каждого контроллера `V_idle`, `V_start`, `V_max` → внести в `config.yaml`.

### Подключение к нашей плате

```
Controller throttle connector          Control board
─────────────────────────────          ─────────────
Red  (+5V out)          ─────────────  NC (изолировать термоусадкой)
Black (GND)             ─────────────  GND (star ground)
SIG                     ─────────────  DAC OUTx  (FL=A, FR=B, RL=C, RR=D)
```

## Reverse (сухой контакт)

Два тонких провода (часто отдельный 2-pin разъём или пара от «переключателя назад»).

| Типичные цвета | Функция |
|---|---|
| Black + Grey | сухой контакт реверса |
| White + Black | сухой контакт реверса |
| два одинаковых тонких | сухой контакт реверса |

Поведение (подтвердить на столе):

- **Разомкнуто** → вперёд
- **Замкнуто** (короткое замыкание пары) → назад

Подключение: коллектор/эмиттер PC817 между этими двумя проводами. Полярность оптопары на стороне контакта обычно не критична (биполярный фототранзистор), но если реверс не срабатывает — поменять местами.

### Проверка

1. Мультиметр в режиме прозвонки: при штатном переключателе реверса пара замыкается.
2. Без переключателя: замкнуть пару перемычкой при нулевом throttle — мотор должен сменить направление при следующем трогании.
3. **Никогда** не замыкать reverse под ненулевым throttle.

## Прочие провода контроллера (не к Pi)

| Группа | Типичные цвета | Куда |
|---|---|---|
| Battery | толстые Red / Black | через контактор на BAT+/BAT− |
| Phase U/V/W | толстые Yellow / Green / Blue | фазы мотора |
| Hall | тонкие Red/Black + Y/G/B | датчики Холла мотора |
| Ignition / Lock | тонкий Red (часто) | замкнуть на BAT+ через ключ/контактор или оставить постоянно на BAT+ после контактора |
| Brake cutoff | пара тонких | NC или нормально замкнутая цепь «тормоз отпущен» |
| Learning / self-learn | пара тонких | только при обучении датчиков |

Ignition-провод: если мотор молчит при наличии throttle — часто нужно подать BAT+ на lock/ignition. В силовой схеме это делается **после** контактора.
